CloudStore893 POS - Demo

Description

Cloud Store 893 at oci.cloudstore893.com is a POS system running in a Node.js container on Oracle Cloud and protected by Oracle Identity Access Management. Cash register clients are available on iPad and Android tablets. The admin interface supports supervisor push notifications, reporting, and table access.

Source Code Repo: github.com/ltm893/cloud-store-893

The following screenshots show 2 transactions:

  1. a split cash/credit sale
  2. a sale with a stored customer that gets an automatic 10% discount.

End-to-end cashier flow: sign in, open till, split cash/card sale, link a customer with card on file, close till with supervisor approval.
